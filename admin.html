Connexion

Connecte-toi avec un token GitHub pour modifier tes projets et les publier directement sur ton site.

Comment créer mon token ?
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens, puis Generate new token.
  2. Repository access : « Only select repositories » et choisis le dépôt de ton site.
  3. Permissions → Repository permissions → Contents : « Read and write ».
  4. Génère le token, copie-le et colle-le ici. GitHub ne le réaffiche plus ensuite.

Le token reste dans ton navigateur et n'est envoyé qu'à api.github.com. Sans lui, personne ne peut modifier ton site, même en ouvrant cette page.
